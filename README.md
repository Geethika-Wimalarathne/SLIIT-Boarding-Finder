# SLIIT Boarding Finder

A full-stack web application designed to help SLIIT students search, filter, and review boarding places near campus, along with listing management workflows for owners and admins.

## Key Features
- **Search & Filter Boardings:** Filter listings by keyword/address, maximum monthly rent (LKR), and distance to SLIIT (km).
- **Student Reviews & Ratings:** Authenticated students can submit star ratings and comments on boarding listings.
- **Role-Based Workflows:** Separate views and workflows for Students, Boarding Owners, and Admins.
- **Image Uploads:** Support for listing images via `/uploads`.

## Tech Stack
- **Backend:** Java, Spring Boot, Spring Data JPA
- **Database:** Microsoft SQL Server (managed via SSMS)
- **Frontend:** HTML, CSS, JavaScript
